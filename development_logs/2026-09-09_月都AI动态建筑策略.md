# 月都 AI 动态建筑策略

- 日期：2026-09-09；作者：Renko。
- 分支：codex/renko-strengthen-lunar-capital；起始提交：048094455542fb1d5e9991cf5467aa01932e33f2。继续月都改革，保留本批已有未提交改动。
- 月都中途成立，直接采用动态建筑策略，不新增开局扩民工阶段或初始化流程。
- 默认建设军工；民工不足优先纠偏，民工充足后补不足的船坞。
- 定义 C = num_of_civilian_factories、M = num_of_military_factories、D = num_of_naval_factories，T = C + M + D + 1。按引擎动态变量口径计算，不另行扣除地图外工厂。
- 本轮初始参数：C/T < 0.30 启动民工纠偏，C/T > 0.40 退出；D/T < 0.15 且 C/T > 0.40 启动船坞纠偏，D/T > 0.20 或 C/T < 0.30 退出。中间区间保留此前策略状态；精确等号不触发对应严格比较。参数为本轮实现选择，非实机平衡结论。
- 民工、军工要求完全控制地区存在未锁定共享空槽。船坞要求同一个完全控制的沿海地区有海军基地及未锁定船坞空槽；失去条件时退出。允许符合条件的占领地区。
- 使用 building_target 数量目标：军工基线 +9999；民工纠偏为民工 +9999、军工 -9999；船坞纠偏为船坞 +9999、民工与军工各 -9999。负值用于配合常驻目标调整方向，不拆除建筑。
- 船坞目标仅存在于带港口启停条件的策略中；民工纠偏不另放负船坞目标，船坞纠偏已在民工低线时退出。
- 全国数量目标不指定施工地点；港口及槽位判断是启停门槛，不承诺仅在检查到的港口州建设。
- 比例由临时变量按需计算，无持久变量、额外 flag、周期钩子或原版覆盖。
