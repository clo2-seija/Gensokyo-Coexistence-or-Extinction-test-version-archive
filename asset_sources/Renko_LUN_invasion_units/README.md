# 月都侵军兵牌源稿

采用用户确认的步兵第二版、中坦第二版、中坦歼比例修订版、重坦歼比例修订版和原版构型中防空第二版。
本目录保存可编辑 SVG、来源清单及两种坦歼的确定性导出脚本；游戏读取 manifest.json 中列出的 PNG，不读取 SVG。

- 大图：152×42，两帧各 76×42。
- 地图小图、文本图：60×12，两帧各 30×12。
- 两帧保持相同彩色兵牌，遵循本机日本 MOD 的当前做法。
- 步兵、中坦、中防空沿用原导出；两种坦歼的小图分别限于 25×9（中型）和 25×10（重型），裁边后等比例缩放并居中放入 30×12，不再各自填满 28×11。
- 三个营注册 medium / medium_white / small；两个支援连同样有完整三组注册。
- 注册名中的 medium_white 沿用引擎约定；日本范本该槽使用彩色小图，本套保持一致。
- 后续修改以 SVG 为源，导出保持透明背景；不可将预览板或工作用放大 PNG 放入 gfx。

## 坦歼比例修订

- 执行 `python asset_sources/Renko_LUN_invasion_units/render_tankdestroyer_icons.py` 可重建六张坦歼贴图；依赖 resvg-py、Pillow。
- 大图保持 SVG 画布，不裁边放大。单帧全部非透明像素边界：中型 (6,11)-(70,38)，重型 (4,7)-(70,37)。
- 小图中型 (2,1)-(27,10)，重型 (2,1)-(27,11)，右下坐标不包含在边界内；两帧分别留边，不以整张图集边缘代替单帧检查。
- 源文件保留既有 v1 文件名，内容已更新为比例修订版；以 manifest.json 中的 export_layout 为导出依据。
