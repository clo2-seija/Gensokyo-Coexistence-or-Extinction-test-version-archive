现有 HTML/JSON 海军规划器及其 README 保留为既有源码和布局参考，不取代本计划。当前登记图标核对规则与海军线重置构想；计划记录不代表授权实施，不修改国策脚本、规划器、GFX、本地化或图片。

## 后续图标核对顺序

以后核对既有海军国策图标时，按以下顺序查找：

1. 先取得国策 ID。
2. 优先在 `interface/Gemsokyo_focus_customicons.gfx` 及其他 `interface/*.gfx` 中搜索 `GFX_<国策ID>` 与 `GFX_<国策ID>_shine`。
3. 沿注册中的 `texturefile`、`animationmaskfile` 检查 `gfx/interface/goals/KYO/` 等实际贴图路径，并查看图片内容。
4. 再核对 `common/national_focus/*.txt` 中的 `icon` 字段及其引用的普通 GFX，作为补充证据，不以该字段替代前述专用 GFX 检索。
5. 如果第一轮没有找到，继续扩大检索全部 `interface/` 与 `gfx/interface/goals/`。对于现有海军国策，应先报告“专用图标位置尚未定位”，继续查找，不得直接报告“没有图标”或要求作者补图。

上述规则只确认现有海军国策的资源状态。以后新增的海军国策仍须单独选定、注册并检查正式图标。
