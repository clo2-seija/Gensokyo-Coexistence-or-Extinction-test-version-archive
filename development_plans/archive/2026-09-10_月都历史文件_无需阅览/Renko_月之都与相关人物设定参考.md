- 服务对象：LUN改革的剧情、人物与主题参考；不构成国策、数值或AI机制实施方案。

- 范围：以《永夜抄》《儚月抄》《绀珠传》相关设定为基础，加入《兽王园》《锦上京》的必要后续补充。不是东方全部出版物的完整考据。

## 1. 来源等级与阅读方法

- **原作文本转录/译文**：资料站明确标为游戏设定文档、游戏对话、官方出版物文本的段落。可以作为原作内容的检索依据，但网站和中文译文不是官方发布端。
- **资料站整理**：编辑者对人物与世界观的概述，可能混合多个作品；需要与原作文本区分。
- **本MOD设定**：本地剧本与玩法事实，独立于原作。
- **创作提示**：本文件对写作方向与误用风险的判断，不是原作追加设定，也不是已采纳设计。

访问说明：本次联网检索获得了下列页面的索引正文/摘录，部分页面直接打开返回468或无法抓取。因此不声称逐页全文核验、通读原书或检查官方游戏附带文件。每项只摘要可见证据，保留具体页面和原作归属；正式采用精细能力限制、逐字台词、结局细节时应回到对应原作复核。没有复制完整原作文本、下载图像或采用同人游戏数值。

## 2. 月之都：适合先掌握的世界观

### 2.1 起源、统治与身份

《儚月抄》设定文本将月人起源关联到地上贤者对污秽与寿命的认识及迁月；月夜见是月都开创者与统治者，永琳与其有关联。不能把MOD中丰姬担任LUN领袖，直接解释为原作丰姬就是月之都最高君主。[S01]

月之都应与人类所见的荒凉月面区分；资料站将其描述为隐藏于月球另一侧的特殊世界。静海、月之海、地月通道等词汇都带有作品的世界观语境，不能直接照搬成现实地理或现代航天规则。[S02]

### 2.2 污秽、生命与永恒

“污秽”与生死、生命活动及寿命密切相关，并不只是卫生污染或道德邪恶。月人排斥污秽，月都维持的无寿命状态也不能直接等同于蓬莱人无法死亡的性质；资料站明确区分无寿命与仍可能被杀死。[S03]

《绀珠传》对话显示，敌人利用了月人拒绝生死的弱点，使月都陷入难以应付的危机。写作时应保留这种文明自身的脆弱性，而不是把“科技高”推成没有任何弱点。[S04]

### 2.3 技术与军力

《求闻史纪》相关材料经月都词条转录，描述了领先地上的枪械、特殊弹道和医药等展示品。这支持技术优势的主题，不支持某个固定现代武器年代、战斗力倍数或全国工业产量。[S02]

月兔承担战斗、调查和劳动，但不同岗位待遇有别。清兰从事危险且低薪的潜伏任务，铃瑚则是地位较高的情报管理人员；不能把所有月兔写成同一种忠诚、处境与职能。[S07][S08]

### 2.4 地月往来与梦境

丰姬的连接山海能力在《儚月抄》被描述为能连接月之海与地上的山，并带部队前往地上。资料站考据页给出了对应小说原文；“部署与交通”可以作为主题，但无限运力、任意落点、永久无补给等游戏规则均不是该证据直接给出的结论。[S05]

《绀珠传》的梦境月都是应对危机的安排，哆来咪参与构建与看守通道。梦境避难所、真正月都与地表不是同一个地点，哆来咪也不是因此就变成月人或永久隶属月军。[S09][S10]

## 3. LUN现有五名人物

### 3.1 绵月丰姬 / Watatsuki no Toyohime

- 月人、绵月依姬的姐姐、受永琳教育的月之公主；与依姬共同担任月之使者首领。[S01][S06]
- 能力重点是连接山海；其地月移动用途见第2.4节。[S05]
- 资料站记述她对月兔较亲切、会带点心，但也承担防卫与拘捕工作。不要只取亲切一面，把她写成与月都制度完全无关的温和人物。[S06]
- **创作提示**：可参考交通、战略部署、对外处置等主题；这是选材方向，不是原作赋予她的现代部长职称。
- 《锦上京》另有净秽设施管理身份，见第6节，不能遗漏作品阶段。

### 3.2 绵月依姬 / Watatsuki no Yorihime

- 月人、丰姬的妹妹，受永琳教育；比姐姐严肃，担任月之使者首领并负责月兔训练。[S01][S11]
- 能力是召唤神灵附体并使用对应力量；《儚月抄》中与登月一行人的符卡战是其重要表现。[S11]
- **创作提示**：训练、军纪和神灵协同可作为主题；不可把姐姐的山海连接能力直接归给她，也不要把一次符卡战胜负换算为现代军队固定倍率。

### 3.3 铃仙二号 / レイセン / Reisen

- 《儚月抄》开头来到地上的月兔，替永琳给绵月姐妹送信，之后成为姐妹身边的新月兔；“铃仙二号”是为区分同名者的称呼。[S01][S12]
- 与铃仙·优昙华院·因幡是两个角色，后者的名字、能力及永远亭经历不能直接整套移植给她。
- **创作提示**：传令、新兵视角、月兔日常可作参考；本次未找到足以单列其个人特殊能力的原作证据，保留未知，不补造能力。

### 3.4 清兰 / Seiran

- 《绀珠传》月兔，地面调查部队Eagle Rabbit成员，负责危险的潜伏渗透且待遇低；能力为从异次元发射子弹。[S07]
- 后续《兽王园》文本显示她已离开月都，在地上寻求自己的归宿，并试图利用带来的宝玉建设月兔乐园。[S07]
- **创作提示**：可以参考渗透和援护主题；若MOD仍让她为LUN服役，应按本MOD采用的时间与人物经历衔接，不能把后续原作的离开经历抹成“始终忠诚”。

### 3.5 铃瑚 / Ringo

- 《绀珠传》月兔，Eagle Rabbit的情报管理人员；职位较高、主要任务是调查，不要求通过战斗获胜；她察觉所处月都是梦境，并对地上产生兴趣。[S08]
- 能力是吃团子越多越强，不是预知未来或天生全知。
- **创作提示**：情报管理与调查可作参考；MOD把她配置为后勤将领是游戏角色分工，不能将该职务反称为原作设定。

## 4. 关联人物：不是默认可招募名单

### 稀神探女 / Kishin Sagume

月都高官，寡言与其说话会使事态逆转的能力有关；效果不保证朝她希望的方向发展。她参与迁都与梦境避难安排，仍敬重永琳。[S10]

《绀珠传》对话将迁都幻想乡称为危机下的保险方案；它与本MOD全面征服地球的殖民叙事不是同一计划。[S13]

**衔接重点**：本MOD“探女是正邪母亲”的剧情属于本MOD设定。原作有探女与天邪鬼性质的关联，不足以推出她与正邪的血缘关系。具体逆转手段应保留因果边界，不能简化成任意许愿。

### 哆来咪·苏伊特 / Doremy Sweet

梦境世界的貘，能力与食梦、造梦有关；应探女请求参与梦境月都及通道安排，但资料站并未将她描述为月军常备军官。[S09]

**创作提示**：梦境交通、避难和信息渠道可作为参考；改变所属或让她无条件支持月都，需要额外剧情理由。

### 八意永琳 / Yagokoro Eirin

前月之贤者、绵月姐妹的老师、药学天才，如今在永远亭侍奉辉夜；她参与月都历史，却不等于在当前月都政权任职。[S01][S14]

**创作提示**：科学遗产、旧师承与间接博弈均有选材空间；不能以“月之头脑”称号为由自动将她加入LUN现役顾问。

### 蓬莱山辉夜 / Houraisan Kaguya

原月之公主，能力涉及永远与须臾；服用蓬莱之药后的流放与永琳共同隐居，是永远亭背景的重要部分。[S15]

**创作提示**：可以用于旧月都与地上生活的对照；“公主”身份不等于支持月都入侵或现任最高统治者。

### 铃仙·优昙华院·因幡 / Reisen Udongein Inaba

曾离开月球、后来生活在辉夜与永琳身边的月兔；她与绵月姐妹的旧关系有《儚月抄》资料支持，和铃仙二号须分开。[S01][S12]

本次主要采集身份与关系，没有完整整理其历代能力表和经历；正式写战斗能力时另核《永夜抄》设定，不从二号或通用月兔能力反推。

### 月夜见与嫦娥

月夜见：月都开创者与王，所查《儚月抄》设定对其保留大量未知；具体内阁、军阶、性格与继承制度不可自行冠以原作之名。[S01]

嫦娥：《绀珠传》纯狐设定将她描述为被幽禁的月之女神、月兔支配者，也是纯狐怨恨的核心对象。不能因其在月都就当作LUN现成可用统帅。[S16]

### 纯狐、赫卡提亚与克劳恩皮丝

纯狐是被怨恨纯化的存在，能力为纯化，对嫦娥抱有强烈仇恨，是月都的外部威胁。[S16]

赫卡提亚是拥有三个身体的地狱女神，曾与纯狐联手对抗月都；克劳恩皮丝是她的部下。她们不是月都阵营的常规增援角色。[S17]

本次仅记录阵营关系；不采用同人常见的家庭关系、配对或战力排行榜，也不据此为LUN新增敌对系统。

## 6. 《锦上京》补充：单独保留作品层次

维缦·浅间的《锦上京》设定转录描述：她被月人限制在浅间净秽山，驱蛇处理污秽（生命信息），维持月都所需的环境；信息暴增令她难以承受。资料站的丰姬条目则补充其管理这一设施的职责。[S18][S06]

这提供了“月都永恒依赖设施、管理与劳动”的设定材料，但不能由此宣布本MOD已存在净秽产业链。本次没有完整核读该作所有结局，也没有将磐永阿梨夜等完整收录；如未来方案确实采用这套设定，再针对所需部分补查。

## 8. 写作时怎样使用

1. 先确认要写的人物或主题，再查本文件对应来源；世界观、能力、故事中的一次行为不要混成同一类证据。
2. 原作依据、本MOD既有设定、助手新拟创作分别标明。原作资料用于理解，不自动推翻作者已经采用的改编。
3. 没有证据的现代官职、装备名称、军队规模、能力代价与冷却时间，应标为拟定内容；不把翻译、考据或玩家梗包装成原作。
4. 对接原MOD登场、宣战、削弱、终局以及人物归属；此文没有批准新机制、新人物或新增周期钩子。
